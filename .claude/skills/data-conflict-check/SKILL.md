# Data Conflict Check

Run this before shipping any output that pulls numbers or facts from more
than one source.

1. List every figure/fact and its source.
2. Compare sources for the same figure. Flag any mismatch.
3. If a mismatch exists, stop. Surface it to Chris first (myrules.md rule
   4). Do not average, guess, or pick one silently.
4. Never let a figure from one venture (EURPAC, Sugar Hill, real estate)
   silently carry into another (myrules.md rule 5).
5. Only proceed to final output once conflicts are resolved or explicitly
   waived by Chris.
