# Workflow: Ghostwrite

Blueprint for `/ghost` requests — emails, marketing copy, social posts.

1. Confirm the venture (EURPAC, Sugar Hill, real estate) if not stated.
   Don't assume it (myrules.md rule 5).
2. If the target is Sugar Hill, run the `locked-facts-guard` skill before
   drafting.
3. Draft in voice (`Safe/myvoice.md`) — no preamble, no filler.
4. If facts come from more than one source, run `data-conflict-check`
   before returning the draft.
5. Return the draft only. Chris reviews and sends.
