# Spartan pass

Target: $ARGUMENTS

## Load first

Read `Safe/myvoice.md` and `Safe/myrules.md`. If the target is a file path, read the whole file. If no target is given, ask for it and stop.

## Cut

- Count the words before you start. Cut 30% minimum. More if the text allows.
- Kill preamble, recaps, hedges, adverbs, and filler phrases.
- Convert passive voice to active.
- Split long sentences. One idea per sentence.
- Merge points that repeat. Turn lists buried in paragraphs into bullets.
- Replace jargon with plain words.

## Keep

- Every fact, figure, name, date, and ask. Cut words, not substance.
- Sugar Hill locked facts, word for word.
- The writer's meaning. Don't add claims or change positions.

## Output

1. The rewritten text, ready to paste.
2. One line: `Words: <before> → <after> (−<percent>%)`.

If a 30% cut would drop a fact or the ask, stop at the deepest safe cut and say which fact blocked the rest. If the target is a file, show the rewrite. Overwrite the file only after Chris confirms.
