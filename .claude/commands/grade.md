# /grade

Give an honest letter grade for $ARGUMENTS (or the most recent draft if no
argument is given).

Rules:

- State the grade first, one line.
- Follow with 3-5 bullets: what earns the grade, what caps it.
- No hedging. If it's a B-, say B- and say why.
- If facts conflict across sources, that caps the grade — call it out
  explicitly (myrules.md rule 4).

Reference: `Safe/myrules.md` ("grade it" signal), `Safe/myvoice.md` (voice).
