# Rule: Data Integrity

- Verify before you state. Strip unverifiable claims. Never fabricate dates,
  statistics, quotes, or attributions (myrules.md rule 3).
- Flag data conflicts before producing output — don't pick a number and move
  on (myrules.md rule 4).
- Never assume figures carry over between EURPAC, Sugar Hill, and real
  estate. Each venture's data stays separate (myrules.md rule 5).
- Never invent testimonials, reviews, or customer quotes ("Never" rule 3).
- When grading, grade honestly. No inflation (myrules.md rule 2).
